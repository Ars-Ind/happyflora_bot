# mama-flora-bot (Telegram, v2)

Telegram-бот для ведения Instagram HappyFlora. В отличие от старой Slack-версии:

- Помнит весь разговор (история сохраняется на диск, переживает перезапуск).
- Понимает свободные формулировки — решения "опубликовать сейчас / позже / это Stories / запомни этот факт" принимает сам Claude через tool use, а не поиск ключевых слов в коде.
- Нет тредов — просто один непрерывный чат, как переписка с человеком.
- Поддерживает: одиночное фото, карусель (несколько фото одним альбомом), видео (Reels), Stories, статистику, долгосрочную память о магазине (новый адрес, акции и т.д.), отложенную публикацию (время вычисляет сам Claude на основе часового пояса Минска).

## Настройка

1. **Токен бота**: напишите [@BotFather](https://t.me/BotFather) в Telegram → `/newbot` → следуйте инструкциям → скопируйте токен в `TELEGRAM_BOT_TOKEN`.
2. **ID пользователей с доступом**: каждый, кому нужен доступ (мама + вы), должен написать [@userinfobot](https://t.me/userinfobot) — он пришлёт числовой Telegram ID. Впишите оба через запятую в `ALLOWED_TELEGRAM_USER_IDS`.
3. Остальные переменные (`ANTHROPIC_API_KEY`, `IG_ACCESS_TOKEN_HAPPYFLORA`, `CLOUDINARY_*`) можно скопировать из старого `.env` — они не изменились.
4. `npm install`
5. `npm start`

## Структура

- `telegram-bot.js` — приём сообщений из Telegram (фото, видео, текст), включая сбор альбомов фото в карусель.
- `claude.js` — «мозг»: хранит историю разговора, формирует системный промпт, вызывает Claude с инструментами (`publish_post`, `schedule_post`, `get_instagram_stats`, `remember_shop_fact`).
- `instagram.js` — публикация в Instagram Graph API (фото, карусель, Reels, Stories, статистика).
- `cloudinary-upload.js` — загрузка медиа в облако для получения публичной ссылки.
- `memory.js` — долгосрочные факты о магазине и история разговора на диске (`data/`).
- `brands/happyflora.json` — профиль бренда (тон, аудитория, цели).

## Важно про data/

Папка `data/` (история переписки + факты о магазине) не должна попадать в git — она уже в `.gitignore`. Она создаётся автоматически при первом сообщении.
